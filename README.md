# サッカーノート V17

- 試合は新モードが初期設定。テーマ設定の試合/TRデフォルトテーマの下で旧モードに切替可能。設定は保存されます。
- 新モード：今日のテーマ、オン・ザ・ボールの攻撃/守備、オフ・ザ・ボールの攻撃/守備。各項目は「できたこと」「次の試合で改善・継続したいこと」のみ。
- 評価は最後の「今日の評価（5段階）」1つ、備考は最後に任意で1つ。プレビューとコピーも対応。
- TR・その他・旧モードはV16の入力方式を維持。「TODAY文章を作成」ボタンはありません。
- V16の履歴・テーマ・下書きを初回に引き継ぎ、V17専用の保存先を使用。V16の保存データは変更しません。
- 形式情報のない既存の試合履歴・下書きは旧モードで開きます。新規作成は設定したモードを使用。切替前の入力は同じ下書き内に保持。
- 履歴の保存済み文章はそのままコピー可能。編集保存時はその入力形式で文章を再生成します。

## 更新方法
ZIPの4ファイルを、V16を配置していた同じサイト・同じパスで上書きし、再読み込みしてください。
履歴や設定は同じブラウザ・同じオリジンのlocalStorageから引き継ぎます。別サイトや別ブラウザへ自動移行はできません。

## 検証
JavaScript構文チェック、主要UI要素・IDの確認、画面要素を模した簡易動作確認を実施。
初期表示、新旧切替と設定保持、新モードの8入力・全体評価、プレビュー生成、履歴保存、V16の履歴・テーマ・下書き引き継ぎ、旧履歴の個別評価とロック維持、TR/その他の描画処理維持を確認しました。
実ブラウザの起動は実行環境の制限で失敗したため、実ブラウザでの表示・クリップボード・PWAオフライン動作は未確認です。

## V17 文章形式の更新
新モードの各項目は「できたこと：本文」「次の試合で改善・継続したいこと：本文」の形式に変更。箇条書き記号は付けず、複数行の入力は改行を保持します。既存の新モード入力に付いている箇条書き記号も、編集時・文章生成時に除去します。備考欄の案内は「感想とか次にかける思いとか何かあれば」。旧モード・TR・その他の形式は維持します。

## 文章形式修正 r3
新モードで保存済みの履歴も、プレビュー・コピー時に現在の文章形式で表示します。旧モード・TR・その他の保存済み文章は維持します。更新したサービスワーカーは自動的に有効化し、取得した最新ファイルをオフラインキャッシュにも反映します。上書き後はオンラインで画面を再読み込みしてください。

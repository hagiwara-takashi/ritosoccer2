# サッカーノート V17（入力・文章レイアウト修正版）

- 試合の新モードが初期設定。テーマ設定の下で旧モードに切替でき、設定を保存します。
- 新モード：試合名、今日のテーマ、オン・ザ・ボールの①攻撃／②守備、オフ・ザ・ボールの③攻撃／④守備、今日の評価（5段階）、備考（任意）。
- 各項目は「できたこと」「次の試合で改善・継続したいこと」のみ。入力欄とプレビュー・コピー文章を同じ構成にしています。
- 文章は「【試合】試合名」「【今日のテーマ】テーマ」と同じ行に出力。振り返りは「できたこと：本文」形式で、備考は記入時のみ出力します。
- 備考の案内：「感想とか次にかける思いとか何かあれば」。
- TRの見出しは練習場所・練習内容を例示。項目ごとの評価入力・生成文章への評価出力を廃止。最後の全体評価は維持します。
- 過去のTR個別評価データと保存済みTR文章は保持。編集して保存したTR文章には個別評価を出力しません。
- 試合の旧モード・その他を維持。「TODAY文章を作成」ボタンはありません。
- V16の履歴・テーマ・下書きをV17専用の保存先へ引き継ぎ、V16の保存データは変更しません。形式情報のない試合履歴・下書きは旧モードで開きます。
- 新モード履歴はプレビュー・コピー時に最新形式で生成します。新規作成は設定したモードを使用し、切替前の入力は下書きに保持します。

## 更新方法
4ファイルをV16/V17と同じサイト・同じパスで上書きし、オンラインで再読み込みしてください。キャッシュも更新します。
データの引き継ぎには同じブラウザ・同じオリジンが必要です。
